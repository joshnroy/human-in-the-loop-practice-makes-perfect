Where epsilon is actually exercised

Before the first practice success the toss classifier is one-class, every draw takes the uninformative branch, and the epsilon coin is never flipped, so all 20-action arms share one trajectory through cycle 4 (checked: sampler draws identical up to cycle 5). eps=0.1 and eps=0 then stay identical through cycle 8, because eps=0.1's coin first fires in cycle 9.
